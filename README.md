# 🌱 Agro Forte, Futuro Sustentável

Projeto Front-End desenvolvido com foco em conscientização ambiental e valorização do agronegócio sustentável.

A página apresenta um layout moderno e responsivo com o tema:

> **“Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”**

---

# 📸 Preview

A página contém:

- Banner principal com imagem de fundo
- Seção sobre sustentabilidade no campo
- Cards informativos
- Área de impactos positivos
- Layout responsivo
- Design moderno utilizando HTML e CSS puro

---

# 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Responsividade com Media Queries
- Imagens via Unsplash
